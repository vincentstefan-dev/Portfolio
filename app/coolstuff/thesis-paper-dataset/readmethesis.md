# Thesis Paper Dataset

This folder contains a JSON-based dataset for screening and organizing academic papers for an exploratory entrepreneurship thesis.

The current thesis direction is:

> Digital freelancers, entrepreneurial self-presentation, signaling, differentiation, and marketplace success in platform-mediated freelance markets.

The dataset is designed for the discovery phase of the thesis. This means the goal is not yet to select only perfect-fit papers. The goal is to understand which papers help develop the theory, context, variables, method, and possible research direction.
